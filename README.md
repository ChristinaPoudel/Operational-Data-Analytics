# Toronto Field Operations & Service Performance Tracker

## Project Overview
This project analyzes Toronto service request data to understand service performance, request volumes, and operational trends across city divisions and wards.

The project uses PostgreSQL for data storage and SQL analysis, Microsoft Excel for reporting, and Microsoft Power BI for interactive data visualization.

## Tools Used
- **PostgreSQL** — Data storage and SQL analysis
- **SQL** — Service request analysis and aggregation
- **Microsoft Excel** — Dashboard with charts and insights
- **Microsoft Power BI** — Interactive dashboard and visual reporting

## Dataset
- Total records: 500,269 service requests
- Data source: Toronto Open Data
- Main fields include creation date, division, service request type, status, and ward.

## Analysis
The SQL analysis examines:
- Service request status distribution
- Request volumes by city division
- Monthly service request trends
- Most common service request types
- Service request distribution by ward
- Data completeness and quality

## Dashboards

### Microsoft Excel
An Excel dashboard presents service request trends through charts, summary insights, and a data source note.

### Microsoft Power BI
The Power BI report includes:
- Total service requests
- Completed, cancelled, and in-progress requests
- Service requests by status
- Service requests by division
- Monthly service request trends
- Top service request types
- Top wards by service request volume
